EPC-ESP32P4-070¶

Version 1.0

Product Overview¶

The EPC-ESP32P4-070 Embedded HMI Display (PN: CS10600-ESP32P4-070E) is an embedded programmable capacitive touch HMI display featuring an ESP32 P4 processor. The product features an embedded mounting design, making it suitable for integration into existing equipment.

It features a 7” IPS display with a maximum brightness of 400 cd/m2. The touch screen is a responsive capacitive screen and supports multi-touch.

The product is powered by an ESP32-P4 processor, making it suitable for applications such as:

  • Smart Home

  • Industrial Automation

  • Healthcare

  • Consumer Electronics

  • Smart Agriculture

  • Retail Self-Service Terminals (POS, Vending Machines)

  • Service Robots

  • Multimedia Player

  • High-Speed USB Host and Device

  • Smart Voice Interaction Terminal

  • Edge Vision AI Processor

  • HMI Control Panel

The product can be programmed with ESP-IDF, ESPHome and other ESP32 ecosystem tools and frameworks that support the ESP32-P4.

Power Input¶

The EPC-ESP32P4-070 Embedded HMI Display can be powered by an input voltage of 9V to 32V DC.

The total power consumption is about 4W max, 3W typical, depending on the load and brightness.

The power input is 3-pin 3.81mm screw terminal, you can also use the USB-C port to power the product while programming.

Attention

  1. In order to use the Isolated Output, you need to add an external Isolated Power to the VDD_ISO and GND_ISO (between 5V and 24V). The power voltage should not exceed 24V.

  2. The output current can reach 500mA for every channel, but it also depends on the isolated source that supplies the power.

  3. In order to use the Isolated Input, you need to add a signal to the IN_X and GND_ISO. A 2.4KΩ resistor, as R6, has been added to limit the input current, as shown in the figure below. This resistor should work well for the 5-24V input signal. If your input signal is less than 5V, please change this input resistor. USB¶

There are 2 x USB2.0 Type-A HOST connectors and 1 x Type-C connector onboard, as shown in the image below.

USB2.0 Host and Type-C Ports

Note

  • USB peripherals such as high-speed flash drives can be connected to the USB 2.0 host ports.

  • Full/Low speed USB devices such as mice and keyboards cannot connect due to the limitation of USB Hub Host software stack, Espressif managed software stack doesn’t support Transaction Translator layer yet.

  • The USB Type-C port is used for debugging and firmware flashing and supports powering the product.

LAN¶

LAN (RJ45) connector provides Ethernet connectivity over standardized Ethernet cable. The integrated Ethernet interface supports up to 100 Mbps data throughput.

The product supports optional PoE (Power over Ethernet), it’s not mounted by default.

RJ45 LAN Connector

4G/LTE¶

4G/LTE Cat 1 module is optional. If you place an order with 4G module included, we will also add a SIM card holder and a 4G/LTE antenna to enable 4G/LTE connectivity.

The SIM card slot does NOT support hot-swapping. Power off the device before inserting or removing the SIM card.

The Cat 1 module doesn’t support GPS.

SIM Card Direction

Attention

The product does not come shipped with the 4G/LTE module by default. If you need to use 4G/LTE, you can contact us when placing an order. We can install the necessary hardware for you.
