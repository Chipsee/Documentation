.. |product| replace:: AIO-ESP32P4-101

.. |PN| replace:: PN: CS12800ESP32P4101A

.. |Product| replace:: The |product| Smart Display

.. |dispsize| replace:: 10.1"

.. |cpu| replace:: Dual-core 32-bit RISC-V, up to 400 MHz; single-core 32-bit LP RISC-V, up to 40 MHz; optional ESP32-C6 co-processor for Wi-Fi 6/Bluetooth LE

.. |storage| replace:: 32MB external SPI Flash

.. |ram_desc| replace:: 768 KB HP L2MEM + 32 KB LP SRAM + 8 KB SPM; 32MB in-package PSRAM

.. |res| replace:: 1280 x 800

.. |bright| replace:: 400 |cd|

.. |dim| replace:: 260.54 x 178.54 x 26.9mm

.. |weight| replace:: 620g

.. |tscreen| replace:: 10-point capacitive touch with 1.0mm armored glass

.. |rtc_desc| replace:: High-accuracy RTC with supercapacitor, can work 1 week after power off **(default)**. High accuracy RTC with lithium coin battery, can work 3 years after power off **(optional)**. 

.. |buzzer| replace:: Onboard buzzer, driven by GPIO

.. |USB| replace:: 2 x USB 2.0 Type-A high-speed host ports; 1 × USB 1.1 Type-C port for firmware flashing and debugging; does not support powering the device.

.. |LAN| replace:: 1 x Gigabit LAN

.. |GPIO| replace:: 0 x GPIO **(default)**, 8 x GPIO **(optional,** by configuring 2 x RS232, 1 x RS485 and 1 x Relay to 8 x GPIO)

.. |can| replace:: 0 x CAN **(default)**; 1 x CAN FD bus, arbitration bit rate up to 1Mbps, data bit rate up to 8Mbps, by configuring 1 x relay to CAN **(optional)**

.. |4g_desc| replace:: Internal CAT1 4G/LTE module, **not mounted by default**

.. |vin_rng| replace:: 9V to 32V DC

.. |cur| replace:: 260mA max at 15V, 200mA typical at 15V

.. |pwr| replace:: 4W max, 3W typical

.. |power_conn_desc| replace:: The power input uses a DC connector with dimensions of 3.4 mm O.D. × 1.7 mm I.D. × 9.5 mm. The product also includes a 3.4 × 1.7 mm to 5.5 × 2.1 mm adapter, allowing either connector size to be used with a suitable DC power supply.

.. |temp| replace:: From -20°C to +70°C

.. |audio| replace:: 3.5mm audio out interface; internal dual channel speaker; front microphone

.. |rs232| replace:: 2 x RS232 **(default)**; RS232_2 can be configured to RS485 **(optional)**; 2 x RS232 can be configured to 4 x GPIO **(optional)**

.. |rs485| replace:: 1 x RS485 **(default)**; up to 2 x RS485 **(optional,** by configuring RS232_2 to RS485); 1 x RS485 can be configured to 2 x GPIO **(optional)**

.. |relay| replace:: 1 x relay with "Normally Closed" and "Normally Open" output; relay NC and NO can be configured to 1 x CAN FD **(optional)**; relay NC and NO can be configured to 2 x GPIO **(optional)**

.. |camera| replace:: 1 x MIPI-CSI (2-lane) interface for connecting a MIPI-CSI (2-lane) 15-pin 1.0mm camera such as a Raspberry Pi camera **(optional)**

.. |wifi_desc| replace:: WiFi 6, Bluetooth LE 5 **(optional, ESP32-C6 is not mounted by default)**

.. |sd_socket| replace:: 1 x TF (micro SD) card slot

.. |case_color| replace:: Black / White
