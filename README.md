# Chipsee Documentation

The source of [chipsee.com/docs](https://chipsee.com/docs/): hardware and software manuals, OS downloads, 3D files and tutorials for Chipsee industrial computers and displays.

- Industrial panel PCs, embedded PCs and all-in-one PCs, powered by Arm, Intel, Raspberry Pi, NVIDIA Jetson and ESP32
- MediaTek handhelds and portable touchscreens
- Industrial displays and HMI displays

Every product manual can also be downloaded as a PDF.

Developers: see [DEVELOPER.md](DEVELOPER.md).
